Keep the same budget on two phones.

- **Settings → Sync between phones.** On your first phone, tap **Create a sync file** and save it in Google Drive (in the file picker, open the menu and choose Drive). Choose a password. On your other phone, tap **Use an existing sync file**, pick the same file and type the password once.
- The file is locked with your password, the same way as a backup. The password is remembered on each phone, sealed by Android's secure key storage, and never sent anywhere. No sign-in and no account with LoonieMate.
- **Changes go across** when you open or leave LoonieMate, shortly after you change something, and every few hours in the background. Settings also has **Sync now**.
- **Both phones can change things.** If each phone changes something different, both changes are kept. If both change the same thing, the newer change wins. Ticking something off, or undoing it, on one phone shows up on the other. Savings moved on both phones add up.
- Today shows when the last sync was. A sync also counts as a backup.
- Works with other cloud apps that appear in Android's file picker too, like Nextcloud. The sync file is an ordinary LoonieMate backup, so the web version can import it.
