A way to start completely fresh.

- **Settings → Reset LoonieMate,** at the very bottom. It erases everything LoonieMate keeps on this phone: the budget, every setting, reminders, and syncing on this phone. Then it starts from scratch, like a new install. Type **RESET** to confirm, so it can't happen by accident. There's a button to make a backup first. The sync file and any backups you saved elsewhere are left alone.
- **Web version:** "Start over" becomes the same Reset LoonieMate, with RESET to confirm, and now clears every setting too.
