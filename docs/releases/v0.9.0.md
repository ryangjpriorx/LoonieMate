Fixes from a full check of the code: paydays, sync and keeping what you type.

- **Weekly and every-two-weeks paydays count correctly.** If the payday you entered was later in the month (or the weekday picker chose the next one), the earlier paydays that month were left out, so the month looked short and food money was too low. Every payday in the cycle now counts. An income's start date still covers a new job.
- **Sync is safer.** If Google Drive or another cloud app hands one phone an older copy of the sync file, LoonieMate no longer treats what's missing from it as deleted or older amounts as changes. Undoing a delete now sticks after a sync, and the sync file is checked after every save.
- **Forms aren't lost when you switch apps.** If Android closes LoonieMate while you're in your banking app, the form comes back with what you'd typed.
- **You're told if something goes wrong saving.** If a change can't be saved (usually a full phone), or the saved budget can't be opened, a card on Today says so and offers a backup or an import. With sync on, a budget that couldn't be opened comes back from the sync file.
- **Web version on iPhone:** iPhone browsers (Safari and Chrome alike) clear a website's saved data after a week without a visit. The web version now explains how to add it to the Home Screen, where it's kept, and has a proper Home Screen icon. It also says LoonieMate at the top instead of Family Budget.
- Behind the scenes: the old names from the first version are gone from the code. Budgets saved by very early test versions may need setting up again.
