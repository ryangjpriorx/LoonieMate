Personal Expenses is now a list, on the Spending tab.

- **List what you usually get and how often:** a $3.25 coffee 5 times a week, a game each payday, a snack every day. Each one shows about what it comes to in a month, and together they're set aside after bills and food. Naming each one is up to you.
- **It's on the Spending tab now** (it's no longer in Settings), with what's planned and what's been logged this month.
- **One tap to log:** each item has a Log button that logs it for today. Logging is still optional.
- Today's Personal Expenses card links to the Spending tab. Getting on track uses the same list.
- Category names on the spending breakdown no longer get cut off.
